# Changelog

## 0.1.0

First public release of Murashka Remote SSH.

- Independent browser SSH sessions, split panes, output search and keyboard controls.
- Two-pane SFTP with local transfers, a UTF-8 editor and queued host-to-host copies.
- On-demand Linux resource sampling over SSH.
- Saved local and SOCKS5 SSH forwarding, optional reverse tunnels and expiring computer bridges.
- Installation scripts, a local administration CLI, temporary owner and guest workspaces, and an HTTPS deployment guide.

The public release starts with direct SSH connectivity. Personal integrations and experimental add-ons are outside this release.
