FEATURES

Keep everyday server work close.

›_

Browser SSH

Open independent shells in split panes, find text in terminal output and share time-limited access to a single host.

⇄

Two-pane files

Browse, edit and copy files between hosts over SFTP. Queue a transfer and follow its status.

◫

Linux monitoring

Sample CPU, memory, disk space and busy processes through the SSH connection.

✓

Security reviews

Inspect accounts, SSH policy, services and update candidates. Save a baseline and download HTML reports.

▣

Remote desktop

Install Openbox or Xfce on a supported server, then open its private VNC display in the browser.

↗

Telegram control

List hosts and check resource samples. Pair with Helper Tool for browser-approved guest links and wg-easy controls.

↪

SSH tunnels

Reach a private service with a local or SOCKS5 listener. Enable reverse forwarding when your SSH policy permits it.

EXAMPLES

Inspect staging from your phone

Send /hosts to your bot, then /connect 1. Open the returned link and enter its password to access that host for 30 minutes.

Review a server after a change

Run a read-only review before and after an SSH policy change. Compare the selected configuration fingerprints against the baseline you accepted.

Open an app that needs a desktop

On a supported Debian or Ubuntu VM, authorize Openbox or Xfce installation. Open the loopback VNC session through your browser.

Copy a release to another host

Choose the build host on the left and staging on the right. Drag a release archive to the destination, then confirm the copy.

QUICK START

Try it on Linux.

With Python 3.12+, venv, Git and OpenSSL installed, start a localhost evaluation. Use a trusted HTTPS reverse proxy for remote access.

Installation and HTTPS guide ↗
Installation · v0.2.0
git clone --branch v0.2.0 https://github.com/sm0k3net/murashka-remote-ssh.git
cd murashka-remote-ssh
./setup.sh
./murashka init --local-tls
./murashka serve

In a second terminal run ./murashka grant, then open the generated URL and enter the password.
