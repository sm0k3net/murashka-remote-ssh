EXAMPLES

Two common tasks.

Open staging from your phone

Send /hosts and /status 1 to see your host and its last sample. Send /connect 1, then approve it in the browser.

Disable a VPN profile

Send /vpn to find the profile ID. Send /vpn-disable 7 and approve the change. Enable it again whenever you need it.

QUICK START

Run it on your Linux host.

Use Python 3.12+, a dedicated Telegram bot, and a trusted HTTPS hostname for browser approvals. Enable Remote SSH, wg-easy, or both.

Installation guide ↗
Initialize Helper Tool
git clone https://github.com/sm0k3net/murashka-helper-tool.git
cd murashka-helper-tool
./setup.sh
./murashka-helper init --origin https://helper.example.org

Configure an integration and the reverse proxy, then run ./murashka-helper serve.
